# Shared contracts

These documents establish vocabulary and ownership before parallel implementation begins. They are conceptual contracts, not permission to invent product behavior. Changes that affect multiple workstreams require coordination and, when material, an ADR.

- [`DOMAIN_TYPES.md`](DOMAIN_TYPES.md) — shared identifiers, quantities, time, and reference concepts.
- [`PLATFORM_CONTRACTS.md`](PLATFORM_CONTRACTS.md) — actor, tenant, authorization, transaction, audit, idempotency, outbox, document, approval, time, and error boundaries.
- [`MODULE_BOUNDARIES.md`](MODULE_BOUNDARIES.md) — modular-monolith ownership and prohibited coupling.
