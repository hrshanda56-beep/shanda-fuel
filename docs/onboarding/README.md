# Onboarding and cutover workbook

[`Shanda_Fuel_Discovery_Setup_Forms_Pack.xlsx`](Shanda_Fuel_Discovery_Setup_Forms_Pack.xlsx) supports station and tenant onboarding. It covers station/location setup, pilot selection, shifts, banks, POS/EcoCash/payment channels, tanks, calibration, pumps/nozzles/meters, suppliers, customers, approvals, cash controls, variance thresholds, tax/accounting confirmations, opening positions, recent history, and operational reference forms.

Blank or unknown real-world values are onboarding or cutover data, not software-development blockers. Do not invent production values, tax treatment, or legal/accounting policy to fill workbook gaps.

## Phase 1B handoff

The reusable onboarding package is split into:

- [Station onboarding checklist](STATION_ONBOARDING_CHECKLIST.md)
- [Business-information collection template](BUSINESS_INFORMATION_TEMPLATE.md)
- [Pilot operational acceptance checklist](PILOT_OPERATIONAL_ACCEPTANCE.md)
- [Role and responsibility matrix](ROLE_RESPONSIBILITY_MATRIX.md)
- [Known gaps and dependencies](KNOWN_GAPS.md)
- [Reusable onboarding runbook](RUNBOOK.md)

Settings → Readiness is a six-area prerequisite indicator (Prices, Tanks, Pumps, Shifts, Payments and Staff). It does not by itself prove station activation, every meter installation, opening meter readings, opening inventory valuation or MFA enrollment. The pilot checklist and runbook require those additional checks before a real station is opened.
